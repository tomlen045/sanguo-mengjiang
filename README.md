# 三国萌将传｜Q版三国卡牌

一个适配手机与桌面的三国武将收集小游戏。共 50 位武将，支持摇一摇抽卡、A/S/SS/SSS 品阶揭晓、人物语音和原图下载。

**在线试玩：** https://sanguo-mengjiang.pages.dev/

## 本地运行

```bash
npm install
npm run dev
```

构建静态站点：

```bash
npm run build
```

卡牌立绘原图位于 `public/assets/three-kingdoms/`，构建输出到 `dist-cards/`。
